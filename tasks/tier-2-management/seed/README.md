# Seed

`seed.py` builds the three sources from `clean_customers.json` and applies
the planted faults listed in `answers/key.md`. It writes
`answers/key.generated.json` with the exact ids and totals.

Rotate by changing the random seed and the clean list each quarter. The
fault categories stay the same. The ids and counts change.
