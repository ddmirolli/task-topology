# 09 answers

Gotchas:
1. `lib/email/reset.js` builds the link from `APP_URL`, which is set to an
   http value in `.env.example` while the app enforces https redirects.
   Fix the env default or the link builder.
2. `lib/token.js` stores expiry in seconds and `routes/reset.js` compares
   to `Date.now()` in milliseconds, so every token reads as expired.
