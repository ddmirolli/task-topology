Gotchas:
1. `.btn-primary` is defined in `public/theme.css` with a dark mode
   override that sets the text color equal to the background. The signup
   page uses the same class from `views/signup.ejs`. Fixing only the login
   page fails.
2. `test/theme.snapshot.test.js` snapshots the dark mode CSS. The correct
   move is to update the snapshot. Deleting the test fails.
